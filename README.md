# EMBER / 深淵の狩人

Godot 4.7.2製の小規模な見下ろしハクスラARPGです。
**ビルドを組む → 遠征で封印を破る → ボスを倒す → 装備を更新する → 深淵に挑む**進行を実装しています。

企画・構成・完成判定は [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md) を参照してください。
本編30〜60分は設計目標です。所要時間・難度は人間の通しプレイで未検証で、アート・音声も仕上げ前です。

現状評価と優先課題は [docs/ASSESSMENT.md](docs/ASSESSMENT.md) にまとめています。
**現在の作業状態・残課題・次の一手は [docs/ROADMAP.md](docs/ROADMAP.md) を参照してください（新セッションはまずここ）。**

## 起動

Godot 4.7.2で `project.godot` を開き、F5で実行します。外部素材は不要です。
レンダラーは GL Compatibility です。

## タイトルと開始

起動するとタイトル画面を表示します。`W`／`S`か矢印で項目を選び、`Enter`／`Space`またはクリックで決定します。

- **CONTINUE**：保存済みのキャラクターで再開します。セーブが無いときは表示されません。
- **NEW GAME**：新しい狩人を始めます。セーブがある場合は上書き確認を表示します。
- **SETTINGS**：音と演出の設定（`F10`と同じ）。**QUIT**：終了します。

`NEW GAME`は進行・装備・才能・個別スキル成長・残火をすべて初期状態へ戻し、`user://character.json`を上書きします。取り消しはできません。

ゲーム中に `Esc` を押すとポーズメニューを開きます。`再開` / `設定` / `操作`（キー一覧）/ `タイトルへ` / `終了` を選べます。`W`／`S`か矢印、`Enter`、マウスで操作し、`Esc`で再開します。

## 素材とライセンス

日本語UIフォントとして Noto Sans JP（Regular / Bold）を `assets/fonts/` に同梱しています。SIL Open Font License 1.1（`assets/fonts/OFL.txt`）。
UIテーマは `assets/theme/ember_theme.tres`、画面表記の日本語は `scripts/loc.gd` に集約しています。効果音は実行時のプログラム合成のため、外部音声素材は使いません。

## 進行

- 最後の焚火を守る狩人として、灰の外縁・埋葬聖域・残火の城塞の3章、各3遠征を攻略します。
- 拠点の右側 **WARP GATE** に近づき **E**。カードのクリックまたは **1〜3** で章を選びます。同章の次の遠征へ自動で進みます。
- 主道の封印I・IIの守備隊を倒すと、東の守護者が解放されます。敵の足元のI・IIと、画面上部の残数が目印です。寄り道の敵や宝箱は攻略必須ではありません。
- 守護者はRare装備を確定ドロップ。3遠征ごとの初回章クリアでは各章固有のRelic装備を持ち物へ直接支給します。
- クリア表示をキーで閉じ、**E**で戦利品を拾って **T**で帰還します。帰還は2秒静止が必要で、移動・攻撃・被弾により中断します。
- 解放済み章は再挑戦可能。過去の章の周回では本編進行や初回報酬は重複しません。
- 9遠征のクリアで物語の区切りと深淵が解放されます。深淵は深度1〜5。深度5の守護者を倒すと最終達成を記録します。
- 深淵はゲートの **4** または専用ボタンで出撃。解放済み深度を選べます。危険条件を付けると敵が強くなり、装備Tierが1上がり、守護者の残火報酬が倍になります。
- 死亡時は **R** で帰還。拾った装備・経験・通貨・攻略進行を保持します。床に残した装備は帰還時に消えます。

## 遠征の地形

入口・狭路・柱の広間・包囲広場・宝物庫・ボス室の6種を部屋として接続します。遠征に入るたびに **3種類の手作りレイアウトからランダムに1つ**を選び、さらに左右反転するので、同じ章でも経路が変わります。章ごとに遮蔽物も変わります。

- **CROSSROADS**：宝物庫が北にあり、2つの封印室を広く通る王道。
- **RING**：中央の回廊で2つの封印室をつなぐ構成。
- **GAUNTLET**：細長く、中央の広場と柱を挟んで進む構成。

ミニマップに通路・柱・封印を表示し、案内矢印は壁を避ける経路へ向きます。

壁は移動・回避・攻撃・引き寄せ・取得を遮り、敵は柱や部屋の入口を回り込んで追跡します。狭路で敵を一列にする、広場でまとめて攻撃する、柱で射線を切る、といった位置取りを使えます。

## 代償付き祭壇

入口の北側にある金色の祭壇で`E`を押すと、遠征限定の契約を選べます。選択はクリックまたは`1`〜`3`。`Esc`／`E`で見送れます。

| 契約 | 強化 | 代償 |
| --- | --- | --- |
| 狂戦の誓い / BERSERKER'S OATH | 通常攻撃+25% | ポーション回復量半減 |
| 残火の契約 / EMBER PACT | 命中時の熱量+50% | 被ダメージ+15% |
| 貪欲の印 / MARK OF GREED | 守護者からRareを追加で1個 | 生存中・今後出現する敵のHP+25% |

1遠征で1つだけ選べ、変更はできません。ボス戦開始後は利用できず、死亡・帰還で効果が消えます。貪欲の追加報酬は撃破した遠征と同じTierで、バッグへ直接収納し分解保護します。通常の守護者ドロップ・章の固有装備報酬も維持します。

選択前のカードに具体的な数値変化、選択後はHUDと装備画面に効果・代償を表示します。装備画面の「Skill hit」は契約込みの通常スキル1回分の威力です。狂戦の誓いはバーストや命中回復を強化せず、残火の契約も1回の攻撃で複数体に当てて熱量を重複獲得することはありません。

## 音と戦闘演出

3スキルの攻撃音、命中・撃破・被弾・バースト・装備取得の効果音を追加。精鋭・ボス撃破などでは45msのヒットストップと小さな画面揺れが入り、Relic取得時は専用音とバナーで知らせます。

`F10`で音量、画面揺れ、ヒットストップ、命中・被弾の点滅を設定できます。設定中は戦闘を停止し、閉じると元の画面に戻ります。設定はキャラクターセーブとは別の`user://feedback.cfg`に保存します。効果音は独自のプログラム合成で、同時再生8音・粒子320個に制限しています。

## オーラと霊力

残火の魔導書の「オーラ」タブで、**常時有効なバフ**を予約できます。

- **霊力**はレベルで増える予約リソースです（`30 + (Lv-1)×2`）。オーラごとに決まった霊力を予約し、合計が上限を超えない範囲で有効にできます。
- 予約したオーラは戦闘中ずっと有効です（発動操作・クールダウン・マナ消費なし）。

| オーラ | 予約 | 効果 |
| --- | --- | --- |
| ASH AURA | 20 | 威力 +15% |
| WARD AURA | 20 | 防御 +8 |
| EMBER FLOW | 15 | マナ回復 +3/s |
| FLEET AURA | 15 | 移動速度 +8% |

- 画面左上に、オーラ有効中は「霊」バッジを表示します。
- ビルド保存（プリセット）には有効なオーラも含まれます。

## 画面表示（HUD）

常時表示は戦闘に必要な最小限に絞っています。

- 左上：体力バー、熱量バー、マナバー、レベル、契約・レリック・熱量満タン・オーラ有効のバッジ。
- 上中央：現在の目標。エリア移動直後は場所名を数秒だけ表示します。
- 中央下：スキルバー（メインスキル・Fバースト・Shift回避・Qポーション）。回避とバーストは使用可否で塗りが変化します。
- 最下部：細い経験値バー。
- 右上：ミニマップ。ボス戦中のみ上部中央にボスのHPと行動を表示します。

次の情報は常時表示せず、メニューや一時的な通知へ移しました。

- 持ち物・倉庫の数、所持残火、才能点、遠征の進捗：持ち物（I）とゲート（E）で確認します。
- 回収モード、レベルアップ、拾得、帰還などの通知：画面中央上に数秒表示して消えます。
- 操作キー一覧：ポーズメニューの「操作」。
- 契約とレリックの詳細：持ち物画面とホバーで確認します。

## ビルドと戦闘

拠点で **B** を押すと残火の魔導書を開きます。`スロット` / `サポート` / `才能と鍛冶` / `パッシブ` / `Modクラフト` のタブを切り替えられます。

スロットタブで基本スキルを1つ、アクティブ枠に最大4つ割り当て、サポートタブで**各スロットに別々に**タグの合うサポートを最大5つリンクします。

| スキル | タグ | 特徴 |
| --- | --- | --- |
| **CLEAVE** | attack / melee / area / physical | 前方の薙ぎ払い。高威力、短射程。 |
| **NOVA** | attack / melee / area / physical | 全周攻撃。低威力で群れに強い。 |
| **LANCE** | attack / pierce / physical | 長い直線の貫通攻撃。 |
| **EMBER BOLT** | attack / projectile / fire | 火弾を放つ。投射物サポートで挙動が変わる。 |

アクティブスキル（基本枠には置けません）。

| スキル | 再使用 | マナ | 効果 |
| --- | --- | --- | --- |
| **EMBER LANCE** | 5秒 | 20 | 直線上の敵をすべて貫く火槍 |
| **CINDER FIELD** | 10秒 | 35 | 指定地点を3秒間燃やし、敵を燃焼・減速 |
| **GUARDIAN BARRIER** | 16秒 | 40 | 最大HPの35%を吸収するシールド（5秒） |
| **BLOOD RUSH** | 18秒 | 45 | 5秒間、攻撃速度+40%・移動速度+30% |

サポートは**レベルを持たず、Tier（T3→T2→T1）で強化**できます。**同じサポートは1キャラに1つまで**で、各スロットのスキルのタグがサポートの必要タグと一致しないと装着できません。

- Tierは右クリックで1段階ずつ強化し、T3→T2が30・T2→T1が60残火。Tierが上がるほど効果量が増え、`T3=1.0倍 / T2=1.25倍 / T1=1.5倍`（効果の増減分に掛かります）。投射物+2などの個数はTierで変わりません。
- 装着できる枠数はそのスロットのスキルのレベルで増えます（Lv.1で2枠、Lv.4で3、Lv.7で4、Lv.10で5）。

| サポート | 必要タグ | 効果 |
| --- | --- | --- |
| MULTISHOT | projectile | 投射物+2、各-40%威力 |
| PIERCE | projectile | 貫通+2体 |
| CHAIN | projectile | 命中後、近くの敵2体へ連鎖 |
| WIDER | area | 範囲+35%、威力-10% |
| CONCENTRATED | area | 範囲-30%、威力+25% |
| POWER | attack | 威力+30%、攻撃速度-10% |
| HASTE | attack | 攻撃速度+25%、威力-10% |
| IGNITE | physical / fire | 命中で2秒燃焼（威力の20%/秒） |
| LEECH | attack | 命中で最大HPの2%回復 |
| CHARGED | attack | 命中で熱量+4 |

- レベルアップで才能点を獲得（合計18点まで）。剛力・体力・速さ・精神に各6点まで配分でき、無料で振り直せます。精神は1点ごとに最大マナ+15・回復+1。
- 通常攻撃の命中で熱量が蓄積。**F**で消費して周囲に大ダメージを与えます。
- 紫の射撃兵とボスは赤い範囲を予告して攻撃します。範囲外への移動か無敵回避で避けてください。章ごとにボスの範囲攻撃が変わります。

## スキルスロット（クリック / 1〜4）

メイン攻撃とアクティブスキルは**同じ1つのスキルプール**です。残火の魔導書の「スロット」タブで、枠を選んでからスキルを選んで割り当てます。同じスキルは1枠だけです。

| 枠 | キー | 内容 |
| --- | --- | --- |
| 基本 | 左クリック / Space | 通常攻撃。攻撃間隔で連射し、**サポート**が付く |
| 1〜4 | 1〜4 | クールダウン制。**攻撃スキルも置ける**。威力は攻撃力とスキルLvで伸びる |

- アクティブ枠は Lv.1 / Lv.3 / Lv.5 / Lv.7 で解放されます。
- 攻撃スキル（CLEAVE / NOVA / LANCE / EMBER BOLT）は基本枠とアクティブ枠のどちらにも置けます。アクティブ枠では再使用待ちとマナを消費して発動します。
- アクティブスキル（EMBER LANCE / CINDER FIELD / GUARDIAN BARRIER / BLOOD RUSH）はアクティブ枠のみです。
- **マナ**：アクティブ枠のスキルはマナを消費します（基本攻撃は0）。マナは時間で回復します。最大マナは `80 + (Lv-1)×6`、回復は `6 + (Lv-1)×0.4`/秒。レベルに加えて、才能「精神」とパッシブ（AZURE WELL / EMBER FLOW）でも増えます。
- マナが足りないスキルはスキルバーの枠が赤くなります。
- サポートは基本枠のスキルにだけ付きます。基本スキルを変えると、タグの合わないサポートは外れます。
- 画面下のスキルバーに、基本・1〜4・Fバースト・Shift回避・Qポーションを並べ、再使用待ちとマナ消費を表示します。
- 遠征と試し斬り場で使えます。拠点では使えません。
- ビルド保存（プリセット）には、基本スキル・サポート・才能・アクティブ枠を含みます。

## スキルとサポートの育成

- 8スキル（攻撃4・アクティブ4）に、それぞれ独立した **Lv.1〜10** と経験値があります。
- 敵撃破時の経験値が、**装備中の全スロットのスキル**に入ります。通常敵は8×章数、守護者は30×章数。通常攻撃・バースト・アクティブのどれで倒しても成長します。
- 空振りや非致死の攻撃では経験値を得ません。切り替えや死亡では成長を失いません。
- 次のレベルまでの必要経験値は100から始まり、1レベルごとに60増えます。Lv.10で成長完了です。
- 1レベルごとにLv.1基準の威力が6%ずつ加算されます。攻撃スキルは射程もCLEAVE +2、NOVA +3、LANCE +8、EMBER BOLT +6ずつ伸びます。
- **サポート枠は各スロットのスキルのレベルで増えます**。Lv.1で2枠、Lv.4で3枠、Lv.7で4枠、Lv.10で5枠。
- 同じサポートは1キャラに1つまでです。別のスロットで使用中のサポートはサポート一覧に使用先が表示されます。
- スキルを切り替えると、新しいタグに合わないサポートは自動で外れます。
- カードには固有アイコン、戦闘タイプ、役割、レベルを表示します。**ホバー**すると背景文・タグ・現在の性能を確認できます。サポートのホバーでは必要タグと適用先を確認できます。
- 表示ダメージは装備・才能・サポート・対応ルーンを反映した通常攻撃の1ヒット分です。DPSは全攻撃が単体に命中する場合の理論値で、移動・回避・範囲内の敵数は含めません。スキルのレベル補正はバーストには掛かりません。
- レベルアップは戦闘中の「MASTERY UP」とエフェクトで通知します。

## 試し斬り場とビルド保存

拠点の南西にある **試し斬り場**（`TRAINING`）に近づいて **E**。標的6体の練習場へ移動します。

- 単体の標的1体と、固まった5体を配置しています。標的は倒れず、反撃もしません。
- 画面左上に **合計ダメージ / DPS / 燃焼ダメージ / 命中数** を表示します。**R**で計測をリセット、**T**で拠点へ戻ります。
- 経験値・残火・ドロップは得られません。熱量や設置物は入場時にリセットします。
- **B** でビルド（基本スキル・アクティブ枠・サポート・パッシブ・才能）を、**I** で装備の付け替え・分解をその場で行え、すぐ計測できます。Modクラフトは拠点のみです。

残火の魔導書のスキルタブ下部に **プリセット3枠**があります。

- **保存**：現在のメインスキル・サポート構成・才能をその枠へ記録します。
- **読込**：記録した構成へ切り替えます。装備は含みません（装備は持ち物で付け替えます）。
- 枠は拠点でのみ操作でき、キャラクターと一緒に保存されます。

## パッシブツリー

レベルアップで得たポイントは、才能（能力値）とは別に **パッシブツリー** へ使えます。残火の魔導書の「パッシブ」タブで、1レベルにつき1点（最大12点）をノードに割り当てます。

- 起点から **攻撃・防御・実用** の3系統に分かれ、親ノードを取らないと先へ進めません。
- ノードは小ノードと、効果の大きい **ノータブル** に分かれます。
- **タグ連動ノード**（投射物ダメージ・範囲・近接ダメージ）は、対応タグを持つメインスキルにだけ効果があります。メインスキルによって有利な経路が変わり、ビルド差が出ます。
- 挙動を変えるノータブル：投射物+1、回避の再使用-20%、命中回復、攻撃速度など。
- マナを伸ばすノード：防御系の **AZURE WELL**（最大マナ+60）、実用系の **EMBER FLOW**（マナ回復+2.5/秒）。
- 割り当ては **クリック**、取り消しは **右クリック**（先のノードから順に）。「リセット」で全解除でき、費用はかかりません。
- パッシブはキャラクターと一緒に保存されます。

## 寄り道：呪われた宝箱

- 各遠征に1つ、**CURSED CACHE** が現れます。ミニマップの紫の四角が目印です。
- 近くで **E** を押し、欲しい部位を選ぶと4体の守護者が出現します。通常よりHPが60%、攻撃力が25%高く、紫の輪で区別できます。
- 4体を倒すと、選んだ部位の**Rare確定・通常より1つ上のTier（上限9）・現在スキルに対応するルーン**の装備と残火を獲得します。
- 報酬は持ち物へ直接入り、自動で分解保護されます。所持品で保護を解除することもできます。
- 任意の挑戦で時間制限はなく、Tで退却できます。未完了で帰還・死亡した場合は宝箱の完了報酬を得られません。取得済みの通常ドロップは保持します。
- 同じ遠征中の二重受取はできません。再出撃時に新しい宝箱が出現します。

## 装備・分解・強化

- 部位は武器・防具・護符。Common・Magic・Rare・Relicの4レアリティです。
- Magic以上には構えに対応するルーンが付きます。一致する装備1つにつき通常攻撃・バーストの威力が12%加算されます。
- **I**で持ち物。ホバーで能力・同部位との差・ルーン・強化段階を確認。拠点か試し斬り場でクリックすると装備します。
- 拠点か試し斬り場で持ち物を **右クリック** すると分解し、残火を獲得します。装備中・倉庫内・保護済みの品は直接分解されません。
- **B**の鍛冶で装備中の品を各3段階まで確定強化できます。武器は攻撃、防具はHP、護符は攻撃速度が上がります。
- 左の **STASH** に近づいて **E**。持ち物をShift＋クリックで預け、倉庫の品をクリックで取り出します。
- グリッドは各6列×4行。ホイール・PREV/NEXTでページ切替。パネル表示中はゲームが停止します。

## Modとクラフト

拠点で`B → MOD CRAFTING`を開き、装備中のMagic・Rareを加工できます。

- 基礎性能とランダムModを分離。Magicは接頭1＋接尾1、Rareは接頭2＋接尾2の最大4Mod。
- 接頭は攻撃・HP・防御、接尾は攻撃速度・燃焼・減速・熱量。装備内で同じ種類は重複しません。
- Mod TierはT3→T2→T1の順に強くなります。装備のBase Tier 1ではT3、2ではT2、3以上ではT1まで加工可能。
- 枠・Mod・Tierを選ぶと、そのModを100%付与し数値だけ範囲内で抽選します。費用は`(4 + Base Tier × 2) × (4 - Mod Tier)`残火。
- 試行時に費用を払い、新旧を比較して採用または見送り。見送り・画面を閉じる・終了では元の装備が残り、費用は返却されません。
- 選んだ1枠以外は変更せず、Modのロックも可能。ロックは加工保護、お気に入りは分解保護として別に扱います。
- CommonとRelicは対象外。従来の3段階強化・ルーン・分解保護は維持します。

旧セーブの装備は基礎性能・旧特殊効果を保持します。初回加工やModロック時に旧特殊効果をT3の接尾Modとして取り込みます。保存形式はv7で、v1〜v6も読み込めます。

## 特殊効果と固有装備

Magic・Rareの接尾Modには以下の特殊効果が付きます。表はT3の値で、T2は効果量1.25倍、T1は1.5倍です。通常攻撃で発動し、複数部位の燃焼・熱量は合算、減速は乗算で適用します。

| 効果 | 挙動 |
| --- | --- |
| Scorching | 命中ダメージの20%/秒で2秒間燃焼。再命中で時間を更新し、同じ敵には最も強い燃焼のみ適用 |
| Frostbound | 1.5秒間、移動速度を15%低下。複数部位は乗算（2部位で約28%、3部位で約39%低下） |
| Charged | 命中した通常攻撃の熱量+4。1回の攻撃で複数の敵に当てても1回分 |

以下のRelicは対応スキルの挙動を変えます。通常のRareと比べて基礎攻撃・HPを抑え、特殊効果との交換条件にしています。

| 装備 | 部位・入手先 | 固有効果 |
| --- | --- | --- |
| Warden's Oath | 武器・第1章 | CLEAVEの3回目の命中攻撃が射程300・威力75%の前方衝撃波を放つ |
| Sentinel's Memory | 防具・第2章 | NOVA攻撃前に250以内の敵を90引き寄せる。ボスには無効 |
| Tyrant's Last Ember | 護符・第3章 | LANCEに左右22度・威力60%の貫通射線を追加 |

- 衝撃波・射線が重なっても同一の攻撃で同じ敵に二重ヒットしません。通常の射線・範囲と重なった敵には強い方のダメージを適用します。
- 各章の初回クリアで確定支給。章クリア後は対応するボスを**3回倒すごと**に再取得でき、ゲートに進捗を表示します。通常のRareドロップも維持します。
- Relicは持ち物へ直接入り、分解保護されます。対応スキルのカードと装備説明で効果を確認できます。
- スキル詳細のDPSには燃焼・追加衝撃波・複数対象への攻撃を含めません。

## ボスの攻略

- **Hollow Warden**：前方への薙ぎ払いと、予告線に沿う突進を交互に使います。薙ぎ払いは背後、突進は横方向に避けます。突進後は2秒間動きを止め、攻撃できます。
- **Crypt Sentinel**：予告線への射撃と守護石2つの召喚を使います。石が残っている間は受けるダメージが30%減りますが、無敵にはなりません。両方を壊すと2.5秒間行動を停止し、3秒間受けるダメージが35%増えます。
- **Cinder Tyrant**：緑の縁で示す安全な扇形を残した火炎輪と、足元を狙う爆発を使います。火炎輪の中心も安全です。HP半分以下では同じ予兆の技を組み合わせ、爆発が増えます。爆発位置は予告後に追尾しません。
- ボスのHPバー下に次の攻撃とフェーズを表示します。緑の **OPENING / ATTACK NOW** が反撃の合図です。ボスへの接触自体ではダメージを受けません。
- 守護石は全スキルの通常攻撃・残火バーストで破壊できます。移動・燃焼・減速の対象にはならず、経験値や撃破数も与えません。
- パネルを開くと予兆も停止します。ボス撃破時はそのボスの未発動攻撃と守護石が消え、帰還時にも戦闘状態をリセットします。

## 精鋭の特殊行動

精鋭はMagic以上の装備を確定ドロップし、頭上の表示で特性を見分けられます。

- **VOLATILE**：死亡位置に1.1秒の予告を出して爆発します。倒したあと離れてください。
- **STORMCALLER**：プレイヤーの位置へ範囲攻撃を予告します。攻撃中も足元を確認してください。
- **SWIFT**：45%速く移動します。接近前に倒すか、回避・減速で距離を取ります。

## 回収・整理のQoL

- **L** または持ち物画面上部で、**MANUAL → AUTO → AUTO + SCRAP** を切り替えます。初期設定は通常の自動回収です。
- **AUTO**：90以内に近づいた装備を回収します。**AUTO + SCRAP**：同じ範囲のCommonだけを残火へ変換し、Magic・Rare・保護品は持ち物へ入れます。
- **Eによる手動回収は常に現物を取得**します。自動分解は床の新規ドロップだけに適用され、既に持っている品は対象にしません。
- 持ち物・装備・倉庫の品にホバーして **F** または **中クリック** で分解保護を切り替えます。保護品には星印が付きます。
- **SORT**：持ち物を保護品優先 → 部位 → レアリティ → Tier順に並べ替えます。
- **SCRAP COMMON**：拠点で、保護していない持ち物のCommonを一括分解します。ボタンには対象数を表示します。
- パネル表示中・一時停止中・死亡中は自動回収しません。回収設定と分解保護は保存されます。
- 画面外の次の敵を **HUNT** の矢印で案内し、封印解除後は **BOSS** に切り替わります。ボスのHPバーと回避の再使用待ちも表示します。

## 保存・互換性

`user://character.json` に持ち物・倉庫・装備・成長・本編・深淵・通貨・ビルド・稼働時間を自動保存します。
導入の閲覧状況とチュートリアルの表示済みヒントは、キャラクターとは別の `user://ui_state.cfg` に保存します。
探索中の敵配置・床の装備は保存せず、起動時は拠点へ戻ります。稼働時間はパネル・一時停止・クリア表示を除くゲーム内時間です。

保存形式はバージョン8です。旧バージョン1〜7を読み込めます。バージョン7以前の旧サポート（POWER/ECHO/SIPHON）は、対応する新サポート（POWER/HASTE/LEECH）として**基本枠のリンク**へ引き継ぎます。4つ目のスキルEMBER BOLTはLv.1・経験値0から追加します。パッシブツリーとオーラはバージョン8で追加し、旧セーブでは未取得の状態から始まります。才能はバージョン8で4種類になり、旧セーブの3種類は「精神」を0として読み込みます。固有装備の入手進捗も保存します。旧装備の性能は自動変更せず、旧セーブでは解放済み章のボス周回で新しい固有装備を集められます。旧形式の回収設定は通常の自動回収になり、自動分解は有効にしません。旧バージョン1・2では、旧マップ2解放済みなら第2章、マップ3解放済みなら第3章から再開できます。旧データには最終ボス撃破記録がないため、深淵は新本編の第3章クリアで解放します。
読み込み不能時は元データを保護して、その起動中の自動保存を停止します。
