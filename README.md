# EMBER / 深淵の狩人

Godot 4製の見下ろし型2Dハクスラ試作です。10ウェーブの敵を倒すとクリア。素材のダウンロードは不要です。

## 起動

Godot 4で `project.godot` をインポートして開き、**F6 / F5** で実行します（通常はF5）。Godot 4.7.2で構文・ヘッドレス動作を確認しています。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印 |
| 攻撃方向 | マウス |
| 連続攻撃 | 左クリック / Space 長押し |
| 無敵回避 | Shift（移動方向、静止時はマウス方向） |
| 強化選択 | カードをクリック / 1・2・3 |
| 一時停止 | Esc |
| 勝敗確定後の再開 | R |

敵の落とす緑の経験値を集めるとレベルアップし、攻撃力・攻撃速度・最大HPから強化を選べます。ウェーブ開始時にHPが10回復します。第3ウェーブから耐久力の高い敵が出現します。

## 構成

- `scenes/main.tscn`：起動シーン
- `scripts/main.gd`：戦闘、成長、描画、UI
- `tests/smoke.gd`：戦闘と進行の回帰確認

テスト：`godot --headless --path . --script tests/smoke.gd`

描画は [Godotのカスタム2D描画](https://docs.godotengine.org/en/stable/tutorials/2d/custom_drawing_in_2d.html) を使い、図形だけで構成しています。現段階はアリーナ戦闘の試作で、装備収集・ダンジョン生成・セーブ・音声は未実装です。
