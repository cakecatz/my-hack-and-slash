# EMBER / 深淵の狩人

Godot 4.7.2製の小規模な見下ろしハクスラARPGです。
**ビルドを組む → 遠征で封印を破る → ボスを倒す → 装備を更新する → 深淵に挑む**進行を実装しています。

企画・構成・完成判定は [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md) を参照してください。
本編30〜60分は設計目標です。所要時間・難度は人間の通しプレイで未検証で、アート・音声も仕上げ前です。

## 起動

Godot 4.7.2で `project.godot` を開き、F5で実行します。外部素材は不要です。
レンダラーは GL Compatibility です。

## 進行

- 最後の焚火を守る狩人として、灰の外縁・埋葬聖域・残火の城塞の3章、各3遠征を攻略します。
- 拠点の右側 **WARP GATE** に近づき **E**。カードのクリックまたは **1〜3** で章を選びます。同章の次の遠征へ自動で進みます。
- 通常敵の70%を倒すと、東の祭壇にいる守護者の封印が解除されます。必要数は画面上部に表示します。
- 守護者はRare装備を確定ドロップ。3遠征ごとの初回章クリアでは選択中の構えに合うルーン装備を持ち物へ直接支給します。
- クリア表示をキーで閉じ、**E**で戦利品を拾って **T**で帰還します。帰還は2秒静止が必要で、移動・攻撃・被弾により中断します。
- 解放済み章は再挑戦可能。過去の章の周回では本編進行や初回報酬は重複しません。
- 9遠征のクリアで物語の区切りと深淵が解放されます。深淵は深度1〜5。深度5の守護者を倒すと最終達成を記録します。
- 深淵はゲートの **4** または専用ボタンで出撃。解放済み深度を選べます。危険条件を付けると敵が強くなり、装備Tierが1上がり、守護者の残火報酬が倍になります。
- 死亡時は **R** で帰還。拾った装備・経験・通貨・攻略進行を保持します。床に残した装備は帰還時に消えます。

## ビルドと戦闘

拠点で **B** を押すとスキルの書を開きます。スキル・サポートのカードと、才能・鍛冶のタブを切り替えられます。

- **CLEAVE**：前方の薙ぎ払い。高威力、短射程。
- **NOVA**：全周攻撃。低威力で群れに強い。
- **LANCE**：長い直線の貫通攻撃。敵を射線に並べると有効。
- 補助効果の以下の数値はLv.1時点です。**POWER**：威力+25%。**ECHO**：威力-15%、攻撃間隔-35%。**SIPHON**：威力-10%、命中した攻撃ごとに最大HPの2.5%を回復。ECHOとSIPHONは第1章クリアで解放します。
- レベルアップで才能点を獲得（合計18点まで）。攻撃・耐久・速度に各6点まで配分でき、無料で振り直せます。
- 通常攻撃の命中で熱量が蓄積。**F**で消費して周囲に大ダメージを与えます。
- 紫の射撃兵とボスは赤い範囲を予告して攻撃します。範囲外への移動か無敵回避で避けてください。章ごとにボスの範囲攻撃が変わります。

## スキルとサポートの育成

- 3スキル・3サポートに、それぞれ独立した **Lv.1〜10** と経験値があります。
- 敵撃破時の経験値が、装備中のスキルとサポートの両方に入ります。通常敵は8×章数、守護者は30×章数。通常攻撃・バーストのどちらで倒しても成長します。
- 空振りや非致死の攻撃では経験値を得ません。未装備・未解放のものは育ちません。切り替えや死亡では成長を失いません。
- 次のレベルまでの必要経験値は100から始まり、1レベルごとに60増えます。Lv.10で成長完了です。
- スキルは1レベルごとにLv.1基準の威力が6%ずつ加算され、射程がCLEAVE +2、NOVA +3、LANCE +8ずつ伸びます。
- POWERは威力補正+2ポイント、ECHOは攻撃間隔の短縮率+1.5ポイント、SIPHONは回復量が最大HPの+0.25%ずつ成長します。
- カードには固有アイコン、戦闘タイプ、役割、レベル、経験値バーを表示します。**ホバー**すると背景文・効果説明・現在装備との差・次のレベルの性能を確認できます。
- 表示ダメージは装備・才能・サポート・対応ルーンを反映した通常攻撃の1ヒット分です。DPSは全攻撃が単体に命中する場合の理論値で、移動・回避・範囲内の敵数は含めません。スキルとサポートのレベル補正はバーストには掛かりません。
- レベルアップは戦闘中の「MASTERY UP」とエフェクトで通知します。

## 寄り道：呪われた宝箱

- 各遠征に1つ、**CURSED CACHE** が現れます。ミニマップの紫の四角が目印です。
- 近くで **E** を押し、欲しい部位を選ぶと4体の守護者が出現します。通常よりHPが60%、攻撃力が25%高く、紫の輪で区別できます。
- 4体を倒すと、選んだ部位の**Rare確定・通常より1つ上のTier（上限9）・現在スキルに対応するルーン**の装備と残火を獲得します。
- 報酬は持ち物へ直接入り、自動で分解保護されます。所持品で保護を解除することもできます。
- 任意の挑戦で時間制限はなく、Tで退却できます。未完了で帰還・死亡した場合は宝箱の完了報酬を得られません。取得済みの通常ドロップは保持します。
- 同じ遠征中の二重受取はできません。再出撃時に新しい宝箱が出現します。

## 装備・分解・強化

- 部位は武器・防具・護符。Common・Magic・Rareの3レアリティです。
- Magic以上には構えに対応するルーンが付きます。一致する装備1つにつき通常攻撃・バーストの威力が12%加算されます。
- **I**で持ち物。ホバーで能力・同部位との差・ルーン・強化段階を確認。拠点でクリックすると装備します。
- 拠点で持ち物を **右クリック** すると分解し、残火を獲得します。装備中・倉庫内・保護済みの品は直接分解されません。
- **B**の鍛冶で装備中の品を各3段階まで確定強化できます。武器は攻撃、防具はHP、護符は攻撃速度が上がります。
- 左の **STASH** に近づいて **E**。持ち物をShift＋クリックで預け、倉庫の品をクリックで取り出します。
- グリッドは各6列×4行。ホイール・PREV/NEXTでページ切替。パネル表示中はゲームが停止します。

## 回収・整理のQoL

- **L** または持ち物画面上部で、**MANUAL → AUTO → AUTO + SCRAP** を切り替えます。初期設定は通常の自動回収です。
- **AUTO**：90以内に近づいた装備を回収します。**AUTO + SCRAP**：同じ範囲のCommonだけを残火へ変換し、Magic・Rare・保護品は持ち物へ入れます。
- **Eによる手動回収は常に現物を取得**します。自動分解は床の新規ドロップだけに適用され、既に持っている品は対象にしません。
- 持ち物・装備・倉庫の品にホバーして **F** または **中クリック** で分解保護を切り替えます。保護品には星印が付きます。
- **SORT**：持ち物を保護品優先 → 部位 → レアリティ → Tier順に並べ替えます。
- **SCRAP COMMON**：拠点で、保護していない持ち物のCommonを一括分解します。ボタンには対象数を表示します。
- パネル表示中・一時停止中・死亡中は自動回収しません。回収設定と分解保護は保存されます。
- 画面外の次の敵を **HUNT** の矢印で案内し、封印解除後は **BOSS** に切り替わります。ボスのHPバーと回避の再使用待ちも表示します。

## 保存・互換性

`user://character.json` に持ち物・倉庫・装備・成長・本編・深淵・通貨・ビルド・稼働時間を自動保存します。
探索中の敵配置・床の装備は保存せず、起動時は拠点へ戻ります。稼働時間はパネル・一時停止・クリア表示を除くゲーム内時間です。

保存形式はバージョン5です。旧バージョン1〜4を読み込めます。旧形式の回収設定は通常の自動回収になり、自動分解は有効にしません。バージョン4のスキル成長も維持します。既存の装備・成長・選択中のビルドは維持し、バージョン1〜3では追加されたスキルとサポートの個別レベルがLv.1・経験値0から始まります。旧バージョン1・2では、旧マップ2解放済みなら第2章、マップ3解放済みなら第3章から再開できます。旧データには最終ボス撃破記録がないため、深淵は新本編の第3章クリアで解放します。
読み込み不能時は元データを保護して、その起動中の自動保存を停止します。

## 開発・検証

- `scripts/main.gd`：拠点、ビルドUI、戦闘、進行、描画
- `scripts/profile.gd`：装備・才能・鍛冶・個別スキル成長・永続化
- `scripts/expedition_event.gd`：任意の宝箱イベントと完了状態
- `scripts/skill_catalog.gd`：スキル説明と、戦闘・プレビューで共有する成長式
- `tests/smoke.gd`：操作・倉庫・戦闘・旧セーブの回帰テスト
- `tests/journey.gd`：全9遠征と深淵5段階、構え、回復、予兆、強化、保存移行
- `tests/mastery.gd`：個別成長・上限・実ダメージ・射程・回復・カード操作・旧形式移行
- `tests/expedition_qol.gd`：宝箱・報酬・自動回収・分解保護・並べ替え・保存移行

```
godot --headless --log-file /tmp/ember-smoke.log --path . --script tests/smoke.gd
godot --headless --log-file /tmp/ember-journey.log --path . --script tests/journey.gd
godot --headless --log-file /tmp/ember-mastery.log --path . --script tests/mastery.gd
godot --headless --log-file /tmp/ember-qol.log --path . --script tests/expedition_qol.gd
```

テストは実キャラクターを読み書きせず、一時セーブのみを使用します。
全進行テストでは敵にテスト用ダメージを与えるため、所要時間・難度の検証には使用できません。
