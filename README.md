# EMBER / 深淵の狩人

Godot 4.7.2製の見下ろし型ハクスラARPGの試作です。

**拠点でマップ選択 → 探索・敵を倒して装備収集 → 帰還 → 装備更新 → 再出撃**をメインループにしています。装備とキャラクター成長は永続します。

## 起動

Godot 4.7.2で `project.godot` を開き、F5で実行してください。外部素材は不要です。

プロジェクトの機能バージョンは `4.7`、開発・検証に使用するエンジンは `4.7.2` です。レンダラーは GL Compatibility を使用します。既存キャラクターを引き続き使用できます。

## 拠点

- WASD／矢印キーでキャラクターを移動できる安全なエリアです。
- 左側の宝箱 **STASH** に近づいて **E**：持ち物とスタッシュを開きます。
- 右側の **WARP GATE** に近づいて **E**：マップ選択を開き、カードのクリックまたは1〜3で出撃します。
- 最初は第1マップのみ。ボス撃破で次のマップが解放され、解放済みマップは繰り返し周回できます。
- 帰還・死亡後は拠点の中央へ戻って全回復。出撃ごとにポーションを3個補充します。

## インベントリ・スタッシュ

- **I**：どこでも持ち物を開閉。**Esc／E／右上のX**でもパネルを閉じられます。
- 各グリッドは **6列×4行**。所持数に応じてページが増えます。ホイールまたはPREV／NEXTで切り替えます。スタッシュ画面では左右それぞれにページがあります。
- 武器・防具・アクセサリをアイコンで表示し、枠の色でレアリティを区別します。
- **ホバー**：名前、レアリティ、部位、Tier、全能力、同部位の装備との差を表示。装備中のアイコンも確認できます。
- **持ち物をクリック**：拠点内で装備交換。元の装備は持ち物へ戻ります。
- **スタッシュを開いた状態で持ち物をShift＋クリック**：預け入れ。
- **スタッシュのアイテムをクリック**：持ち物へ取り出し。
- パネル表示中は移動・戦闘が一時停止します。探索中は持ち物を確認でき、装備変更は帰還後に行います。

## 探索中の操作

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印 |
| 攻撃方向 | マウス |
| 連続攻撃 | 左クリック / Space 長押し |
| 無敵回避 | Shift |
| 近くの装備を拾う | E |
| HPを50%回復 | Q（出撃ごとに3回） |
| 拠点へ帰還 | T（2秒静止。移動・攻撃・回避・被弾で中断） |
| 持ち物の表示 | I |
| 一時停止／パネルを閉じる | Esc |
| 死亡後に拠点へ戻る | R |

マップは画面より広く、カメラがプレイヤーを追従します。ミニマップの赤点が通常敵、金点がボスです。敵は各地に配置され、近づくと追跡を開始します。時間制限・無限ウェーブはありません。ボス撃破後も装備を拾ってから自分で帰還できます。攻略途中でもTで帰還できます。

## 装備と成長

- 部位：武器・防具・アクセサリ。
- レアリティ：Common・Magic・Rare。色は白・青・金。
- 能力：攻撃力、最大HP、防御、攻撃速度。上位マップほど装備の基礎性能が高くなります。
- 通常敵は確率で装備をドロップ。各出撃の最初の撃破は装備確定、ボスはRare確定です。
- 装備変更は拠点で行います。拾っただけでは能力は変わりません。
- 撃破経験値で永続的にレベルアップし、基礎攻撃力とHPが上昇します。
- 死亡しても取得済み装備と成長は維持します。床に残した装備は帰還・終了で消えます。

## 保存

持ち物・スタッシュ・装備中アイテム・レベル・経験値・マップ解放は `user://character.json` に自動保存します。再起動時は拠点から再開し、探索中の敵配置・落ちているアイテムは復元しません。旧ウェーブ版には保存機能がなかったため、初回は新規キャラクターになります。

スタッシュ追加に伴い保存形式はバージョン2になりました。バージョン1の既存データは持ち物・装備・進行を維持して読み込み、スタッシュは空の状態から始まります。次回の自動保存で新形式へ更新します。

壊れた保存データを読み込んだ場合は元ファイルを保護し、その起動中の自動保存を無効化して画面に通知します。

## 開発

- `scripts/main.gd`：拠点UI、探索、戦闘、マップ遷移、描画
- `scripts/profile.gd`：装備生成、装備交換、倉庫移動、永続成長、保存・復元
- `tests/smoke.gd`：メインループ・戦闘・保存の回帰テスト（実キャラクターのセーブは変更しません）

テスト：`godot --headless --path . --script tests/smoke.gd`

現段階はループの検証用です。マップは固定配置の簡易フィールドで、地形障害物・ランダムダンジョン・スキルツリー・クラフト・売買・音声は未実装です。
