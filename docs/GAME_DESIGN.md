# EMBER / 深淵の狩人 — ゲーム企画

## 体験の軸
崩壊した世界の最後の焚火を守る狩人として、三つの封印を解き、灰の王を倒す。
「敵の群れを気持ちよく倒す → 戦い方に合う装備を選ぶ → 苦手な敵に合わせて組み替える → 次の難度へ」が中心。
一人用・買い切り相当の小規模作品。オンライン、取引、複数職業、巨大ツリーは作らない。

## 30〜60分の構成（未実測の目標）
| 区間 | 目安 | 学ぶこと・報酬 |
| --- | --- | --- |
| 拠点と第1章・灰の外縁 / 3遠征 | 0〜15分 | 3種の構え、回避、装備比較。補助効果の解放 |
| 第2章・埋葬聖域 / 3遠征 | 15〜30分 | 射撃敵・範囲予兆、才能配分、分解と強化 |
| 第3章・残火の城塞 / 3遠征 | 30〜45分 | 装備と構えの相乗効果、灰の王、物語の区切り |
| 深淵・深度1〜5 | 45分以降 | 危険条件を選んで報酬を増やす。深度5の王が当面の最終目標 |

各遠征は群れを倒して封印を解除し、守護者に挑む。最低撃破数を表示し、ボス直行だけで進行が終わらないようにする。
同じ遠征の強制周回や待ち時間では尺を稼がない。失敗時も装備と経験は保持し、再出撃できる。
解放済み章で装備を集め直せる。深淵は入場消耗品不要で、失敗による進行停止を避ける。

## ビルド
- **CLEAVE / 薙ぎ払い**：前方近接・高倍率。ボスへの位置取り重視。
- **NOVA / 環状斬り**：周囲攻撃・低倍率。群れに飛び込む爽快感。
- **LANCE / 灰の槍**：長距離の細い貫通攻撃。射線を揃えて戦う。
- 補助は **POWER**（威力）、**ECHO**（低威力・高速）、**SIPHON**（低威力・命中回復）の排他選択。
- レベルごとの才能点を攻撃・耐久・速度に配分。拠点で無料リセットし、短いゲームでも試行錯誤を可能にする。
- **F / EMBER BURST**：通常攻撃で溜めた熱量を消費する範囲攻撃。雑魚処理とボスの隙への差し込み。

## スキル育成と情報設計
- 選択肢ではなく育てる対象にするため、3スキル・3サポートをそれぞれLv.1〜10の独立した習熟度として扱う。
- 敵撃破時に装備中の2つが同量の経験値を得る。未装備は成長せず、切り替えても経験は保持。空振りによる放置育成はできない。
- 必要経験値は100、160、220…と増加。スキルは威力と射程、サポートは固有の長所が伸びる。ランク補正は通常攻撃にのみ適用する。
- スキルカードには固有の紋章、役割タグ、実ダメージ、レベル・経験値を置く。詳細にはフレーバー文・挙動・現在装備との比較・次レベルの変化を示す。
- 成長と戦闘とプレビューは同じ計算式を使う。DPSは単体へ連続命中した場合の参考値と明示する。
- 才能・鍛冶は別タブに移し、スキルを眺めて比較するための面積を確保する。

## 装備と経済
3部位を維持し、比較負担を抑える。装備に「その構えを強化するルーン」が付き、単純なTier比較以外の判断を作る。
不要品は分解して残火へ。装備中の武器・防具・護符を各3段階まで確定強化できる。
ボスはRare確定。初回章クリアでは固有ルーン装備を自動支給し、拾い忘れで主要報酬を失わせない。
深淵の危険条件は敵HP・攻撃力・速度に作用し、報酬Tierと通貨を増やす。無制限インフレではなく深度5で区切る。

## 寄り道と周回QoL
- 各遠征に任意の呪われた宝箱を置く。欲しい部位を先に選び、強化された4体の守護者を倒してRareを確定入手する。
- 本編のランダムドロップと、寄り道の狙った部位を得る報酬を併用する。ルーンも現在のスキルに合うものにし、装備更新の目標を作る。
- 宝箱には入場料・時間制限を設けず、途中撤退を許可する。完了報酬は直接収納し、自動で分解保護する。
- 通常の自動回収を初期設定とし、希望者はCommonの自動分解を選べる。手動回収は現物のまま取得できる。
- お気に入り保護、持ち物ソート、Common一括分解で整理負担を減らす。レア品の自動廃棄は行わない。
- 次の敵・ボスへの方向表示、ボスHPバー、回避の待ち時間表示で探索・戦闘の判断を助ける。

## 戦闘と読みやすさ
近接兵・射撃兵・精鋭を混ぜる。ボスは足元範囲、追尾位置への予告爆発、連続範囲攻撃を章ごとに使い分ける。
危険範囲を着弾前に表示し、無敵回避で抜けられる。ボス封印の進捗、次の目標、スキル準備状態を常時表示。
パネル中は停止。戦闘中の組み替えは不可。拠点でまとめて組み替え、すぐ再挑戦する。

## 実装と完成判定
まず進行・ビルド・経済・敵挙動・深淵・既存セーブ移行を一続きに実装し、回帰テストで検証する。
次に人間の通しプレイで所要時間、死亡箇所、装備更新回数、各構えの偏りを計測する。
完成版の条件は、初見で30〜60分以内に深淵へ到達し、3構えのいずれでも攻略でき、操作説明なしで次の目標が分かること。
背景・キャラクターの専用アート、効果音・BGM、日本語ゲーム内フォント、コントローラー対応は別の仕上げ工程。
今回の実装だけで演出面まで製品品質になったとは見なさない。
