# 次に実装したいアイデア

> 現在の作業状態・残課題・優先度は [ROADMAP.md](ROADMAP.md) に集約しています。この文書は 2026-09-22 時点のアイデアで、一部は実装済みです。

2026-09-22時点の企画と実装状況。案1「ボス固有行動」は実装済みで、難度の通しプレイ調整は未完了。案2「部屋と分岐」と案3「音と演出」も実装済み。案4「代償付き祭壇」も実装済み。案6「Mod指定クラフト」も実装済み。案5・7・8は未実装。
目標は「30〜60分で本編を終え、完成したビルドでもう少し遊びたくなる」こと。
固有装備・特殊効果・宝箱・自動回収は既にあるため、それらを活かす戦闘と探索を優先する。
規模の小・中・大は現実装に対する相対的な目安で、作業時間の見積もりではない。

## 1. ボスは「見て避ける → 攻撃を差し込む」

- **Hollow Warden**：前方薙ぎ払い＋直線突進。突進後に2秒の隙。背後に回る判断を覚える。
- **Crypt Sentinel**：予告線の射撃＋守護石2つ。石を壊すと短時間弱体化。石の破壊は必須にせず、範囲型と単体型の両方に攻略手段を残す。
- **Cinder Tyrant**：安全な扇形を残す火炎輪＋追尾爆発。HP半分で組み合わせが変わるが、新しい予兆の読み方は要求しない。
- 初回は単独の技を見せ、後半で組み合わせる。長い無敵時間や避けられないダメージで尺を稼がない。
- 合格条件：攻撃前後が視覚で区別でき、近接でも反撃でき、3スキルすべてで倒せる。

## 2. 地形と経路で装備の強みを活かす

- 狭路はLANCE、広場はNOVA、単独の強敵はCLEAVEが活躍しやすい構成にする。どのスキルでも主道を通れることを優先する。
- 部屋は「入口・狭路・柱の広間・包囲広場・宝物庫・ボス室」の6種。最初は手作り接続で成立させ、その後に配置順の変化を加える。
- 主道は短く、宝箱や祭壇へは任意の寄り道。全域の撃破割合ではなく、主道の封印2つを攻略条件にして、寄り道を強制しない。
- 壁は移動だけでなく攻撃の射線も遮る。敵の経路探索、回避の壁抜け防止、出口の接続保証を一緒に実装する。
- 合格条件：通行不能・敵の引っ掛かり・壁越し攻撃がなく、入口からボスまで迷わず進める。

## 3. 手触りを作る

- スキルごとに異なる攻撃音、軽い命中音、重い精鋭撃破音、固有装備専用の取得音を用意する。
- 強い一撃にだけ短いヒットストップを入れ、連続攻撃の操作を妨げない。燃焼の毎フレーム処理では発生させない。
- 危険範囲は攻撃エフェクトより読みやすくする。揺れ・フラッシュは個別に弱めるか無効にできるようにする。
- 合格条件：集団戦でも音が過密にならず、予兆と回避操作が埋もれない。

## 4. 代償付き祭壇：短い遠征の中にも選択を作る

- **狂戦の誓い**：通常攻撃+25%、ポーション回復量半減。
- **残火の契約**：熱量獲得+50%、被ダメージ+15%。
- **貪欲の印**：守護者の装備報酬+1個、遠征中の敵HP+25%。
- 数値は初期案。取得時に代償を明示し、取得を見送れる。効果は帰還・死亡・再出撃で終了し、永続装備を失わせない。
- 毎回必須の作業にならないよう、主道の外に置く。効果中の表示と戦闘プレビューを一致させる。

## 5. Lv.5で選ぶ熟練分岐

- **CLEAVE**：近距離の単体に強い「断頭」／外周の敵まで捉えやすい「長刃」。
- **NOVA**：中心ほど高威力の「炉心」／周辺部で熱量を集める「火花」。
- **LANCE**：最初の敵への威力を上げる「穿孔」／後方の敵ほど強くなる「貫徹」。
- まずは各スキル2択だけ。固有装備は挙動、熟練分岐は狙い方を変える役割に分ける。
- 低レベルの別スキルを試しにくくならないよう、最も育ったスキルより大きく遅れたものへの経験値補助も検討する。
- 合格条件：ボス用・集団用の違いがあり、常に片方だけが優位にならない。

## 6. 装備の完成へ向かう鍛冶

- 残火を使い、Magic・Rareの燃焼／減速／熱量増加を選んで付け替える。基礎能力・Tier・強化段階は維持する。
- Relicの固有効果は変更できない。結果と費用を事前に表示し、外れを引き続ける方式にはしない。
- ドロップで良い基礎性能を探し、鍛冶で役割を仕上げる。章クリア数回分を要求するような高額設定は避ける。

## 7. 実験を支えるQoL

- 拠点に単体標的と5体の集団標的。10秒間の総ダメージを直撃・燃焼・追加攻撃に分けて表示する。
- 標的は経験値・通貨・熱量の持ち越しを生まない。戦闘終了時に拠点の通常状態へ戻す。
- 保存枠はスキル・サポート・才能から開始。装備の保存は安定したアイテムIDを導入してから追加する。
- 拠点でのみ切り替え可能。将来装備を含める場合、売却・分解済みの品は複製せず欠品表示にする。

## 8. 深淵を遊ぶ小さな目標

- 初回目標は「異なる2スキルで守護者撃破」「危険条件付き深度3クリア」「深度5クリア」の3つ。
- 主な報酬は称号・見た目・少量の残火。全達成を本編の進行条件や大きな永続火力ボーナスにしない。
- ベストタイムと死亡回数を記録し、自分のビルドの成長を振り返れるようにする。通信ランキングは作らない。

## 推奨する実装順

1. **戦闘の質**：ボス固有行動 → 命中・撃破の演出。既存マップで先に反撃と爽快感を確認する。
2. **遠征の変化**：地形・主道と寄り道 → 祭壇。所要時間と進行条件をこの段階で再計測する。
3. **ビルドの遊び幅**：指定鍛冶 → 試し斬り場 → 熟練分岐。比較・検証手段を先に用意する。
4. **クリア後の目標**：深淵ボード。人間の通しプレイで30〜60分の到達時間と難度を最終調整する。

**実装済み**：Hollow Wardenの2行動と反撃の隙、Sentinelの射撃と守護石、Tyrantの火炎輪とHP半分での複合攻撃。
攻撃形状、安全地帯、無敵回避、守護石、撃破後の後処理をテストし、既存の進行・保存の回帰も確認した。
攻撃・命中・撃破・被弾・取得の合成効果音、45msのヒットストップ、画面揺れ、Relic専用表示、F10設定を追加した。音の同時再生と粒子に上限を設け、音量・揺れ・停止・点滅を個別調整できる。
6種類の部屋・上下の任意分岐・章別の柱・主道の2封印を追加した。移動と回避、敵の追跡、攻撃と取得の遮蔽、突進と守護石の配置を共通地形で処理し、全配置の接続と任意攻略を検証した。
入口脇の祭壇で3つの契約を選べるようにした。選択前の実数プレビュー、効果中表示、既存・追加出現する敵へのHP補正、通常報酬とは別の保護Rare支給、死亡・帰還時の解除を検証済み。契約はボス戦開始前までとし、直前取得だけで追加報酬を得る抜け道を防ぐ。
Torchlight: Infiniteの接頭／接尾と方向性を選ぶ加工を参考に、4枠・T3〜T1・枠保護・対象Mod指定・結果の採用／見送りを実装した。対象ModとTierは確定、数値だけ範囲抽選。
次の実装候補は **試し斬り場とビルド保存**。人間の通しプレイによる難度・時間の検証は別途必要。
巨大スキルツリー、大量の装備部位、オンライン、無制限の階層追加は、この規模では後回しにする。
