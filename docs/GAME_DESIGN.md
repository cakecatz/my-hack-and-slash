# EMBER / 深淵の狩人 — ゲーム企画

## 体験の軸
崩壊した世界の最後の焚火を守る狩人として、三つの封印を解き、灰の王を倒す。
「敵の群れを気持ちよく倒す → 戦い方に合う装備を選ぶ → 苦手な敵に合わせて組み替える → 次の難度へ」が中心。
一人用・買い切り相当の小規模作品。オンライン、取引、複数職業、巨大ツリーは作らない。

## 30〜60分の構成（未実測の目標）
| 区間 | 目安 | 学ぶこと・報酬 |
| --- | --- | --- |
| 拠点と第1章・灰の外縁 / 3遠征 | 0〜15分 | 3種の構え、回避、装備比較。補助効果の解放 |
| 第2章・埋葬聖域 / 3遠征 | 15〜30分 | 射撃敵・範囲予兆、才能配分、分解と強化 |
| 第3章・残火の城塞 / 3遠征 | 30〜45分 | 装備と構えの相乗効果、灰の王、物語の区切り |
| 深淵・深度1〜5 | 45分以降 | 危険条件を選んで報酬を増やす。深度5の王が当面の最終目標 |

各遠征は主道2か所の守備隊を倒して封印を解除し、守護者に挑む。封印ごとの残数と対象の敵を表示する。宝物庫や任意の敵は封印条件に含めず、装備を狙う寄り道として選べる。
同じ遠征の強制周回や待ち時間では尺を稼がない。失敗時も装備と経験は保持し、再出撃できる。
解放済み章で装備を集め直せる。深淵は入場消耗品不要で、失敗による進行停止を避ける。

## ビルド
- **CLEAVE / 薙ぎ払い**：前方近接・高倍率。ボスへの位置取り重視。
- **NOVA / 環状斬り**：周囲攻撃・低倍率。群れに飛び込む爽快感。
- **LANCE / 灰の槍**：長距離の細い貫通攻撃。射線を揃えて戦う。
- 補助は **POWER**（威力）、**ECHO**（低威力・高速）、**SIPHON**（低威力・命中回復）の排他選択。
- レベルごとの才能点を攻撃・耐久・速度に配分。拠点で無料リセットし、短いゲームでも試行錯誤を可能にする。
- **F / EMBER BURST**：通常攻撃で溜めた熱量を消費する範囲攻撃。雑魚処理とボスの隙への差し込み。

## スキル育成と情報設計
- 選択肢ではなく育てる対象にするため、3スキル・3サポートをそれぞれLv.1〜10の独立した習熟度として扱う。
- 敵撃破時に装備中の2つが同量の経験値を得る。未装備は成長せず、切り替えても経験は保持。空振りによる放置育成はできない。
- 必要経験値は100、160、220…と増加。スキルは威力と射程、サポートは固有の長所が伸びる。ランク補正は通常攻撃にのみ適用する。
- スキルカードには固有の紋章、役割タグ、実ダメージ、レベル・経験値を置く。詳細にはフレーバー文・挙動・現在装備との比較・次レベルの変化を示す。
- 成長と戦闘とプレビューは同じ計算式を使う。DPSは単体へ連続命中した場合の参考値と明示する。
- 才能・鍛冶は別タブに移し、スキルを眺めて比較するための面積を確保する。

## 装備と経済
3部位を維持し、比較負担を抑える。装備に「その構えを強化するルーン」が付き、単純なTier比較以外の判断を作る。
不要品は分解して残火へ。装備中の武器・防具・護符を各3段階まで確定強化できる。
ボスはRare確定。初回章クリアではスキルの挙動を変える固有装備を自動支給し、拾い忘れで主要報酬を失わせない。
深淵の危険条件は敵HP・攻撃力・速度に作用し、報酬Tierと通貨を増やす。無制限インフレではなく深度5で区切る。

## 装備の個性と獲得目標
- Magic・Rareに燃焼・減速・熱量増加の特殊効果を付け、火力の数値だけでなく、継続ダメージ、安全性、バースト頻度のどれを伸ばすか選べるようにする。
- 各章に1つ、CLEAVEの衝撃波・NOVAの引き寄せ・LANCEの追加射線を与えるRelicを配置する。基礎能力や通常装備の特殊効果と引き換えにスキルの挙動が変わる。
- 初回章クリアで確定支給し、以降も対応ボス3撃破で確定取得。ゲートで入手先と残りの進捗を確認できる。
- 精鋭は死亡時爆発・予告範囲攻撃・高速移動の違いを持ち、Magic以上確定で挑む理由を作る。

## 寄り道と周回QoL
- 各遠征に任意の呪われた宝箱を置く。欲しい部位を先に選び、強化された4体の守護者を倒してRareを確定入手する。
- 本編のランダムドロップと、寄り道の狙った部位を得る報酬を併用する。ルーンも現在のスキルに合うものにし、装備更新の目標を作る。
- 宝箱には入場料・時間制限を設けず、途中撤退を許可する。完了報酬は直接収納し、自動で分解保護する。
- 通常の自動回収を初期設定とし、希望者はCommonの自動分解を選べる。手動回収は現物のまま取得できる。
- お気に入り保護、持ち物ソート、Common一括分解で整理負担を減らす。レア品の自動廃棄は行わない。
- 残る守備隊・ボスへの経路案内、ボスHPバー、回避の待ち時間表示で探索・戦闘の判断を助ける。

## 戦闘と読みやすさ
近接兵・射撃兵・精鋭を混ぜる。第1ボスは薙ぎ払いと突進、第2ボスは直線射撃と破壊可能な守護石、第3ボスは安全な扇形を持つ火炎輪と予告爆発を使う。
ボスは攻撃後に行動を止めて反撃の隙を作る。守護石の破壊は任意の弱体化手段で、長時間の無敵を設けない。第3ボスはHP半分で既知の技を組み合わせる。
危険範囲を着弾前に表示し、無敵回避で抜けられる。ボス封印の進捗、次の目標、スキル準備状態を常時表示。
パネル中は停止。戦闘中の組み替えは不可。拠点でまとめて組み替え、すぐ再挑戦する。

## 実装と完成判定
まず進行・ビルド・経済・敵挙動・深淵・既存セーブ移行を一続きに実装し、回帰テストで検証する。
次に人間の通しプレイで所要時間、死亡箇所、装備更新回数、各構えの偏りを計測する。
完成版の条件は、初見で30〜60分以内に深淵へ到達し、3構えのいずれでも攻略でき、操作説明なしで次の目標が分かること。
背景・キャラクターの専用アート、効果音・BGM、日本語ゲーム内フォント、コントローラー対応は別の仕上げ工程。
今回の実装だけで演出面まで製品品質になったとは見なさない。

## 戦闘の音と演出

スキル別の合成効果音と、命中・撃破・被弾・取得の音を追加。重い攻撃の45ms停止は重複加算せず、通常攻撃や燃焼の各フレームでは発生させない。画面揺れは描画のみに適用し、照準・HUD・当たり判定を変えない。Relic取得は専用音とバナーを表示する。

F10で音量・揺れ・ヒットストップ・命中／被弾の点滅を変更でき、キャラクターとは別に設定を保存する。音声は最大8音、うち2音を重要音に確保し、粒子は320個まで。実際の爽快感・音の好みは試遊で調整する。

## 遠征の部屋と移動

入口、狭路、柱の広間、包囲広場、宝物庫、ボス室の6種を固定接続する。章で柱配置、遠征で宝物庫の上下が変わる。柱の広間と包囲広場の守備隊がそれぞれ封印を守り、両方を倒すとボスを解放する。全域の撃破割合は進行条件に使わない。

移動・回避・射線・引き寄せ・取得は共通の壁矩形で判定する。敵の経路は十分な幅を持つ床のグリッドで求め、広い直線では直接追跡する。ボスの突進も壁で停止し、守護石は到達可能な床へ配置する。ミニマップは床・柱・封印・宝箱を表示し、方向矢印は通れる経路に沿う。

自動テストは接続・衝突・封印条件を保証する。30〜60分という本編の目標時間と、狭路での集団戦の難度は人間の通しプレイで調整する。

## 遠征限定の代償付き祭壇

入口の主道から少し外れた位置で、任意に1契約を選ぶ。狂戦は通常スキル威力1.25倍・ポーション回復0.5倍、残火は命中熱量1.5倍・被ダメージ1.15倍、貪欲は敵HP1.25倍と守護者の保護Rare追加1個。装備・キャラクター保存の数値は変更しない。

既存の敵はHP割合を保って補正し、宝箱の追加守護者にも補正する。貪欲の報酬は既存ドロップやRelicと独立し、同遠征Tierでバッグへ直接支給する。通常攻撃・ポーション・被ダメージ・熱量の実計算とプレビューを一致させる。

見送り可能、重複選択・変更不可、ボスの交戦・被弾後は選択不可。効果は死亡・帰還・次の遠征で消える。カードを開いている間は戦闘を停止し、HUDと装備画面で契約と代償を確認できる。数値の有利不利は試遊で調整する。

## Modと方向性を選ぶクラフト

参考は[Torchlight: Infinite SS6公式のクラフト改修](https://torchlight.xd.com/us/ep8)。基礎属性と接頭／接尾の分離、対象Mod群を選んだ追加・置換という考え方を採用する。本作では30〜60分の規模に合わせ、最大4枠、7種類、3段階、残火1通貨に縮小する。完全再現や全シーズンの機構の導入はしない。

Magicは接頭1＋接尾1、Rareは2＋2。ドロップは同系重複なしで抽選し、基礎Tierによって強いMod Tierを解放する。基礎性能とModの合計を比較表示し、全戦闘計算に適用する。旧装備は基礎性能を再抽選せず、既存特殊効果を等価のT3接尾として保持する。

クラフトは装備中の1枠を選び、指定した種類とTierを確定で付け、数値だけ範囲内で抽選する。他枠を保持し、任意の枠ロックも可能。事前に費用と範囲を示し、試行後は新旧比較して採用・見送りを選べる。費用は試行時消費で返却しない。画面を閉じる・終了では旧装備を維持する。Relicは対象外とし、通常装備の完成度との選択を残す。

保存形式v7。装備・倉庫・バッグのMod構造、種類、枠、Tier、数値範囲、保護フラグを検証し、不正データはキャラクターへ反映しない。v1〜v6は従来性能のまま読める。新しいクラフトの価格とドロップの成長速度は試遊で調整する。
